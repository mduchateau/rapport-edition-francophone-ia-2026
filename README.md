# IA : les récits anxiogènes gagnent les librairies

Analyse de 1 318 livres francophones sur l'intelligence artificielle, publiés entre 2017 et 2026 : 23,3 % portent une empreinte anxiogène marquée dans leur titre ou leur description.

**Rapport complet en ligne :** https://mduchateau.github.io/rapport-edition-francophone-ia-2026/

## Contenu

- `index.html` — le rapport complet (autonome, aucune dépendance externe hors polices Google Fonts)
- `data_report.csv` — les 1 318 ouvrages notés (titre, auteurs, éditeur, scores et justifications)
- `vocabulaire_anxiogene_2026.09.19_23.18.csv` — fréquence des mots du nuage de mots (sur 307 livres anxiogènes)
- `assets/` — couvertures (sprite), image d'en-tête, visuel de partage

## Méthodologie

Chaque livre est noté séparément sur son titre et sur sa description (en double aveugle : la notation de l'un n'a jamais accès à l'autre), par Claude Sonnet 5, sur une grille de notation fixe calibrée sur un lot de 50 livres. Détail complet dans la section Méthodologie du rapport.
